## 📌 Project Overview

Athlete-Chatbot is a static web-based athletic awareness platform integrated with an IBM Watsonx Assistant chatbot named **Roshx**.

The platform is designed to provide structured information about endurance sports (running, marathon, half-marathon, interval training, etc.) and enable interactive user queries through a deployed IBM Watsonx conversational agent.

This project demonstrates:

* Frontend development using HTML, CSS, and JavaScript
* Domain configuration and production deployment
* Cloud-based chatbot integration using IBM Watsonx Assistant
* Static website hosting with custom domain configuration
* Real-world DevOps-style deployment workflow

---

## 🎯 Problem Domain

### The Problem

Most beginner and intermediate athletes:

* Lack structured knowledge about endurance training.
* Get overwhelmed by scattered online content.
* Have no centralized interactive platform for athletic queries.
* Rely on inconsistent fitness advice from social media.

There is a need for:

* A structured educational athletic platform
* Simple, accessible information on endurance science
* Interactive Q&A support for users

---

## 💡 Proposed Solution

Athlete-Chatbot provides:

1. A static informational website explaining endurance sports.
2. Categorized content including:

   * Running basics
   * 5K events
   * Half Marathon
   * Full Marathon
   * Interval training
3. An integrated IBM Watsonx Assistant chatbot (**Roshx**) to:

   * Answer user queries
   * Provide training-related explanations
   * Offer structured responses from configured intents

The chatbot is not AI-built manually — it is deployed using IBM Watsonx Assistant cloud configuration and embedded into the website.
